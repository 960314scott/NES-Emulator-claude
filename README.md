# NES Emulator

A NES emulator written in JavaScript, packaged as a Windows app with Electron.

- Mappers: 0, 1, 2, 3, 4, 7, 66
- Audio: pulse x2, triangle, noise, DMC
- Controls: Arrow keys = D-pad, X = A, Z = B, Shift = Select, Enter = Start

## Run from source
    npm install
    npm start

## Build the exe
    npm run dist

The exe appears in `dist/`. ROM files are not included; use your own legally obtained ROMs.
